# VTubeTogether

Приложение для прямой передачи изображения VTube Studio между компьютерами с Windows. Отправка и приём запускаются независимо. Каждый приёмник воспроизводит один входящий поток.

## Подключение

1. На принимающем ПК выберите UDP-порт (по умолчанию `42042`) и нажмите **Запустить приёмник**. Передайте отправителю IP, порт и **Код подключения**.
2. На отправляющем ПК откройте VTube Studio. В VTubeTogether выберите окно захвата, введите данные приёмника и нажмите **Подключить отправитель**.
3. Для двусторонней передачи повторите эти действия в обратном направлении. На каждом ПК можно одновременно запустить свой приёмник и подключить свой отправитель.
4. При обрыве запущенный отправитель повторяет попытки. Если принимающее приложение закрылось, запустите приложение и снова включите приёмник на том же порту. Код сохраняется в профиле Windows.

В локальной сети укажите внутренний IP принимающего компьютера. Для подключения через интернет принимающий ПК должен быть доступен по UDP на выбранном порту. При IPv4 за домашним роутером обычно понадобится перенаправить UDP-порт на приёмник и разрешить входящий UDP в брандмауэре. При CGNAT можно использовать доступный с обеих сторон IPv6 или адрес в общей VPN. Для двусторонней передачи это условие относится к обоим приёмникам.

Код подключения подтверждает личность приёмника и даёт право отправлять ему видео. Передавайте его только тому, кого хотите подключить.

## OBS и Discord

На приёмнике нажмите **Окно для OBS**. В OBS добавьте **Захват окна** и выберите **VTubeTogether • Видео для OBS**. Используйте метод захвата Windows Graphics Capture и включите захват клиентской области. Выберите однотонный фон в VTube Studio и добавьте к источнику фильтр **Хромакей**. [Захват окна](https://obsproject.com/kb/window-capture-sources) · [Хромакей](https://obsproject.com/kb/chroma-key-filter)

Если изображение опережает голос в Discord, увеличьте **Задержку видео**. Поле принимает от 0 до 3000 мс, изменение применяется во время приёма. Если изображение уже отстаёт от голоса, оставьте значение 0 и регулируйте задержку звука там, где сводите источники.

Окно VTube Studio может находиться за другими окнами. Держите его развёрнутым на рабочем столе. При сворачивании Windows или само приложение могут приостановить обновление содержимого.

## Сборка

Для запуска нужны Windows 10 версии 2004 или новее и Edge WebView2 Runtime с поддержкой H.264. Для сборки установите Node.js 22.12 или новее, Rust MSVC и Visual Studio Build Tools с компонентом **Desktop development with C++**. [Требования Tauri](https://v2.tauri.app/start/prerequisites/)

```powershell
npm ci
npm run tauri -- build
```

Установщик x64 появится в `src-tauri/target/release/bundle/nsis`. Для разработки используйте `npm run tauri -- dev`.

## Видеопоток

Windows Graphics Capture снимает выбранное окно. Приложение вырезает клиентскую область в физических пикселях и при необходимости пропорционально уменьшает её до 1920 × 1080. OpenH264 кодирует поток с частотой до 30 FPS и целевым битрейтом 3 Мбит/с. Видео идёт по прямому зашифрованному QUIC-соединению, а приёмник воспроизводит его в WebView2. Базовая задержка зависит от рендеринга источника, скорости кодирования и состояния сети.
